# PayMate AI 🚀

## Overview
PayMate AI is an advanced, AI-driven conversational checkout assistant designed to bridge the gap between customers and instant PayPal payments. Built for the PayPal AI Hackathon, it analyzes customer purchase intent in real-time and dynamically generates secure, tailored payment invoice links.

## Key Features
* **Smart Intent Analysis:** Instantly processes user chat requests.
* **Dynamic Link Generation:** Creates customized secure checkout links based on specific customer items and requests.
* **Premium UI:** Features a sleek, modern dark-mode graphical user interface optimized for seamless user experience.

## Tech Stack
* Python 3
* Tkinter (GUI Framework)
* Requests / JSON
